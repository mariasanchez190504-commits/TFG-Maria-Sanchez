# Código del Trabajo de Fin de Grado
Este repositorio contiene los códigos utilizados para el tratamiento y análisis de los datos del Trabajo de Fin de Grado.

## Contenido

El repositorio incluye dos códigos principales:

### `crear_cubos`

Código encargado de leer los archivos individuales, *singles*, y generar el cubo de datos utilizado posteriormente en el análisis.

### `reduccion`

Código encargado de procesar el cubo de datos generado previamente. En resumen, este código realiza la imagen blanca, genera imágenes en bandas espectrales concretas, detecta estrellas, las compara con el catálogo Gaia, extrae espectros, realiza la correlación cruzada y compara los resultados obtenidos con Gaia.

## Datos y resultados

Los datos originales no se incluyen en este repositorio debido a su elevado tamaño.

Las gráficas, imágenes y resultados obtenidos a partir del procesamiento se encuentran recogidos y explicados en la memoria del Trabajo de Fin de Grado.
